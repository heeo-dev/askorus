- OpenCode 토큰은 하한이다(위). 비교 한 번 시간은 요청 시간만 센 것이라, 나누기·계획·정리 시간은 빠져 있다.
- P0-6 정답 라벨과 근거는 Claude 계열이 다는 데 도왔다. Claude 엔진이 정답에 유리할 수 있어 사람 확인 조건을 두었고, 걸리지 않았다.
- unsure가 아닌 same·absent에서 숫자가 맞지 않는 것은 숫자 검사만 잡는다. 숫자가 없는 반대 말(모델 이름, 예·아니요)을 판정 AI가 확실하지 않은 same으로 달면, 이제 같은 말에 보인다(빠른 모델 측정에서는 0개).
