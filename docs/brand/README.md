# Askorus brand

브랜드 원본(SVG)과 쓰는 규칙이다. 앱이 쓰는 PNG는 `app/scripts/render-brand.mjs`가 이 그림과 같은 모양으로 만든다.

## 파일

| 폴더 | 내용 |
|---|---|
| `icon/` | 앱 아이콘(살구 바탕 + 원 셋 말풍선, 세 입). `-foreground`는 바탕 없는 전경, `-monochrome`은 입과 경계가 실제로 뚫린 단색 |
| `logo/` | 글자 로고. `askorus-logo-*`가 기본(원 o), `askorus-logo-character-*`가 캐릭터(입 o). 배경별 `dark`, `light`, `apricot`, 단색 `mono`(밝은 바탕), `mono-light`(어두운 바탕), 투명 `-transparent` |
| `lockup/` | 아이콘 + 글자 로고 가로 조합 |
| `android/` | 안드로이드 적응형 아이콘 원본 층(108 좌표) |

## 색

| 용도 | 색 |
|---|---|
| 살구, 아이콘 바탕 | `#FFAD85` |
| 잉크, 아이콘 도형, 살구 바탕의 글자 | `#2A1408` |
| 밝은 바탕의 'Ask' | `#DD5A26` |
| 어두운 바탕 / 그 위 'orus' | `#151618` / `#EDEBE7` |
| 밝은 바탕 / 그 위 'orus' | `#FCFAF8` / `#1D1A17` |

'Ask'만 강조색이고 나머지는 글자색이다. 밝은 바탕에는 살구 `#FFAD85` 대신 진한 살구 `#DD5A26`을 쓴다. 작은 본문 글자에는 강조색을 쓰지 않는다.

## 크기와 여백

- 아이콘은 32px 이상, 앱 화면에서는 48px 이상을 권한다.
- 글자 로고는 폭 120px 이상, 160px 이상을 권한다. 그보다 좁으면 아이콘만 쓴다.
- 바깥 여백: 아이콘은 한 변의 1/8, 글자 로고는 높이의 1/4, 가로 조합은 그 안 아이콘 한 변의 1/4.

## 지킬 것

- 가로세로 같은 비율로만 키우고 줄인다. 원 o를 타원으로 늘이지 않는다.
- 꼬리의 길이·각도·위치를 바꾸지 않는다. 로고 o의 꼬리는 아이콘 왼쪽 원의 보이는 잉크 원(반지름 14.5)과 같은 비율이다(로고 o 반지름 35.52, 배율 35.52/14.5).
- 입 구멍은 실제로 뚫린 구멍이다. 바탕색으로 덧칠한 그림으로 바꾸지 않는다.
- 눈, 혀, 음표, 그림자, 그라데이션, 외곽선을 덧붙이지 않는다. 다른 AI 회사의 로고나 대표색을 섞지 않는다.
- 로고 글자는 윤곽선이다. 글꼴로 다시 쳐서 만들지 않는다.

## 문구

| | 한국어 | English |
|---|---|---|
| 슬로건 | 질문은 내가, 토론은 AI들이. | You ask. The AIs debate. |
| 설명 한 줄 | 여러 AI의 답, 토론을 거쳐 더 나은 하나로. | Many AI answers, debated into a better one. |
| 기능 한 줄 | AI들의 의견이 같은 곳과 다른 곳을 한눈에. | See where the AIs agree, and where they don't. |
| 설치 안내 | 내 PC에 연결해 쓰는 AI 답변 비교·토론 앱 | Compare AI answers and let them debate, through your own PC. |

긴 줄표(—)를 쓰지 않는다. 한국어는 '다르다'를 쓴다('갈리다'를 쓰지 않음). 여러 AI의 답이 같다는 것을 정답의 보장처럼 쓰지 않는다.

## 글꼴

글자 로고는 Noto Sans KR ExtraBold(800)의 윤곽선으로 만들었다. Noto Sans KR은 SIL Open Font License 1.1로 배포된다(https://openfontlicense.org). 앱은 글꼴 파일을 싣지 않는다.
