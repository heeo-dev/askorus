  3. 영어 'All at once'가 탭 이름으로 긴지: 'All at once'로 확정.
  4. 비교 카드 순서: (2026-11-05 C6에서 카드와 함께 없어짐) 다른 말 → 확인 필요 → 같은 말 → 한 AI만(2026-10-31). 확인 필요는 숫자가 어긋나는 등 직접 봐야 할 문장을 모은 카드입니다('확실하지 않음' 표시만으로는 넣지 않음, 2026-11-01 판정 검증 뒤 사용자 결정).
