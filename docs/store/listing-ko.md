**자세한 설명** (4,000자 이내)

```
질문은 내가, 토론은 AI들이.

Askorus는 질문 하나를 여러 AI에게 한 번에 묻는 앱입니다. 답이 모이면 사회자 AI가 정리하고, 의견이 다른 곳은 AI끼리 토론하게 합니다. 여러 AI의 답, 토론을 거쳐 더 나은 하나로.

■ 이렇게 동작해요
1. 질문: 폰에서 한 번 묻습니다.
2. 여러 답: 켜 둔 AI들이 각자 답합니다.
3. 사회자: 사회자 AI가 모든 답을 읽고 종합 답변을 씁니다. AI들의 의견이 같은 곳과 다른 곳을 한눈에 보여 줍니다.
4. 토론: 원하면 의견이 다른 곳을 놓고 AI끼리 토론합니다. 사회자가 쟁점을 고르고, AI들은 생각을 유지하거나 바꾸며, 끝나면 쟁점마다 결과를 정리합니다.

■ 주요 기능
· 여러 AI에게 한 번에 묻기: Claude Code, Codex, OpenCode
· 사회자 AI의 종합 답변과 같은 곳·다른 곳 표시
· AI끼리 토론, 쟁점마다 합의인지 상황에 따라 다른지 정리
· 이어서 묻기, 한 AI나 사회자에게만 묻기
· AI마다 모델과 생각 깊이 고르기
· 대화 기록은 폰에만 저장
· 개발자용: 내 PC의 Claude Code 세션을 폰에서 보고, 새로 시작하고, 이어 쓰기
· 한국어와 영어, 밝은 화면과 어두운 화면

■ 필요한 것
· Windows PC (macOS는 준비 중)
· PC와 폰에 Tailscale (개인은 무료)
· PC에 설치하고 로그인해 둔 공식 AI 프로그램: Claude Code, Codex, OpenCode 중 하나 이상. 이미 쓰고 있는 구독이나 무료 계정을 그대로 씁니다.
· PC 에이전트 askorus-agent. 받는 곳과 설치 방법은 앱 첫 화면과 GitHub에 있습니다.

■ 개인정보
· Askorus는 우리 서버를 두지 않습니다. 질문은 폰에서 내 PC로 가고, PC의 공식 AI 프로그램이 각 AI 회사로 보냅니다.
· 질문을 받은 AI의 회사가 그 질문을 받습니다. 종합 답변을 쓰는 사회자 AI의 회사는 질문과 모든 답을 받고, 토론하면 답한 AI들의 회사가 서로의 답과 토론 발언을 받습니다.
· 대화 기록은 폰에만 저장됩니다. 분석, 광고, 오류 보고 도구를 넣지 않았습니다.

■ 안내
Askorus는 독립 프로젝트입니다. 어떤 AI 회사의 공식 제품도 아니며, Anthropic, OpenAI 등과 제휴하거나 보증을 받지 않았습니다. Claude, Codex 등의 이름은 각 회사의 상표입니다.
```
